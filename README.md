# Athos Moraes Website

This repository contains the React + Vite source for Athos Moraes' personal website.

## Stack

- React
- TypeScript
- Vite
- GitHub Pages deployment via `.github/workflows/pages.yml`

## Development

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Project Structure

- `src/` application source
- `public/` static files and images
- `dist/` production build output

## Deployment

The site is configured to build and deploy to GitHub Pages from the `master` branch using the workflow in `.github/workflows/pages.yml`.
